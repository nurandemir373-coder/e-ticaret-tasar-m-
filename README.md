## 🇹🇷 Türkçe / Project Overview

Bu proje, **Yozgat Bozok Üniversitesi Bilgisayar Programcılığı** Dönem Projesi kapsamında kişiselleştirilmiş hediyelik ve tasarım ürünler için geliştirilmektedir.

### 📌 Proje Hakkında
Müşterilerin kişiselleştirilmiş hediyelikler (fotoğraf, anahtarlık, takvim, şönil çiçekler vb.) sipariş edebileceği, özel isim ve tarih notu ekleyebileceği dinamik bir e-ticaret ve katalog web sitesidir.

### 🛠️ Kullanılan Teknolojiler
* **Frontend:** HTML5, CSS3, JavaScript
* **Backend:** PHP
* **Database:** MySQL / phpMyAdmin

### ✨ Temel Özellikler
* Ürün kataloğu ve kategoriye göre filtreleme
* Ürün detay sayfasında kişiselleştirme / özel not alanı
* Sepet ve sipariş oluşturma formu
* **Yönetim Paneli (Admin):** Ürün ekleme, silme, güncelleme ve sipariş takibi

## 🇬🇧 English

This project is being developed as a Term Project for **Yozgat Bozok University Computer Programming** department for custom design and gift products.

### 📌 About The Project
A dynamic e-commerce and catalog web system where customers can order personalized gifts (photos, keychains, calendars, chenille flowers, etc.) and add custom name/date notes.

### 🛠️ Technologies Used
* **Frontend:** HTML5, CSS3, JavaScript
* **Backend:** PHP
* **Database:** MySQL / phpMyAdmin

### ✨ Key Features
* Product catalog and category-based filtering
* Customization / special note field on the product detail page
* Cart and order creation form
* **Admin Panel:** Product management (add, delete, update) and order tracking
